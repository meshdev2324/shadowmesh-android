# ShadowMesh Android Client

This is the official Android client for ShadowMesh, a forensic-resistant VPN ecosystem.

## Features
- **Material 3 UI**: Clean, modern interface following the ShadowMesh Design System.
- **WireGuard Core**: High-performance VPN tunneling.
- **Quantum Tunneling**: Advanced DPI evasion via packet fragmentation.
- **Camouflage Mode**: Hides the VPN app during physical device inspections.

## Build Instructions
This repository contains the UI and Android-specific logic. It depends on the pre-compiled ShadowMesh Rust Core binaries.

> [!NOTE]
> This repository is a mirror of the Android module from the private ShadowMesh monorepo.

1. Open this directory in Android Studio.
2. Ensure you have the Android SDK and NDK installed.
3. Sync Gradle and click 'Run'.
